## 🍛 マトンカレー（本格スパイシー仕立て）

マトンの力強い旨味とスパイスの香りが引き立つ、本格的なカレーのレシピです。

## 材料
| 具材 | 量 |
| --- | --- |
| マトン（カレー用・角切り） | 400g |
| 玉ねぎ | 大1個 |
| トマト缶（ダイスカット） | 1/2缶 |
| おろしにんにく | 小さじ1 |
| おろし生姜 | 小さじ1 |
| プレーンヨーグルト | 大さじ3 |
| カレールー | 1/2箱 |
| 水 | 600ml |
| サラダ油 | 大さじ2 |

## 作り方
1. 玉ねぎを薄切りにし、フライパンで飴色になるまでじっくり炒めます。
2. マトン肉にヨーグルトを揉み込み、30分ほど置いて肉を柔らかくしておきます。
3. 鍋に油、にんにく、生姜を入れて熱し、香りが立ったらマトン肉を入れて表面を焼き固めます。
4. 炒めた玉ねぎ、トマト缶、水を加え、弱火でマトンが柔らかくなるまで40〜60分ほど煮込みます。
5. 一旦火を止め、カレールーを割り入れて溶かし、再び弱火でとろみがつくまで混ぜながら煮込みます。
6. 完成。
